# TA05_Uri-aPincay
#Este portfolio profesional es una plataforma interactiva diseñada para gestionar y exhibir proyectos técnicos de forma dinámica. El sistema integra un motor de búsqueda en tiempo real y filtrado avanzado mediante JavaScript, permitiendo una navegación fluida a través de diversas tecnologías y lenguajes de programación. Visualmente, implementa una arquitectura responsive basada en unidades relativas y un diseño modular que asegura una experiencia de usuario óptima en cualquier dispositivo. En las secciones de detalle, destaca el uso de un carrusel de imágenes personalizado y una estructura semántica limpia en HTML5 y CSS3. Es un proyecto escalable enfocado en la presentación profesional de competencias en desarrollo de software y sistemas.
