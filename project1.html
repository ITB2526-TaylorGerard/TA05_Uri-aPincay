📄 Descripción del proyecto — Página Web de Portfolio Personal

Este proyecto consiste en el desarrollo de una página web de portfolio personal, creada con el objetivo de presentar de forma clara, visual y profesional los distintos trabajos y proyectos realizados durante el curso, así como mostrar mis conocimientos técnicos en desarrollo web.

La web ha sido diseñada siguiendo una estructura modular y escalable, permitiendo añadir nuevos proyectos de forma sencilla en el futuro. Se ha priorizado una experiencia de usuario clara, una navegación intuitiva y un diseño moderno adaptado a cualquier tipo de dispositivo.

🛠️ Lenguajes y tecnologías utilizadas

  • HTML5: estructuración semántica del contenido con etiquetas como header, main, section y footer.
  • CSS3:
    • Layouts con Flexbox y Grid
    • Diseño responsive para distintas resoluciones
    • Paleta de colores basada en tonos azules
    • Animaciones suaves y efectos hover
    • Escalado automático usando unidades relativas y clamp()
  • JavaScript (JS):
    • Carrusel de imágenes en la página del proyecto
    • Navegación preparada para futuros proyectos
    • Estructura lista para ampliar funcionalidades
  • Git & GitHub: control de versiones y publicación del proyecto. El botón “View Code” enlaza al repositorio.

🔄 Procedimiento de desarrollo

  1. Diseño previo: boceto inicial de la estructura (index, projects, detalle y contacto).
  2. Estructuración HTML: jerarquía clara, semántica y coherente.
  3. Diseño CSS: estilos progresivos, coherencia visual y responsive.
  4. Implementación JS: carrusel y elementos interactivos.
  5. Optimización: pruebas en distintas resoluciones y navegadores.

🎯 Objetivo del proyecto

El objetivo principal es mostrar de forma profesional mis conocimientos en desarrollo web y disponer de una base escalable para incorporar más proyectos. También sirve como apoyo para entrevistas técnicas y presentaciones académicas.
